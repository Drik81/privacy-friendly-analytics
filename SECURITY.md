# Security

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Contact the project maintainer privately through the contact information published on the DrikWeb website or GitHub profile.

## Scope

This repository is a reference implementation. The demo dashboard is intentionally unauthenticated to keep local setup simple. Production deployments must add authentication and authorization.

Do not commit production connection strings, credentials, or telemetry containing personal or sensitive data.
